# API GET_Genesys

Instalación, comandos, pruebas y estado real: [README principal](../README.md).

Este componente usa Laravel 12 y Sanctum, sin frontend. Las rutas están en `routes/api.php`; las transferencias requieren un token exclusivo `sync:write`. El esquema real de CASABLANCA debe inspeccionarse y migrarse antes de recibir datos.
